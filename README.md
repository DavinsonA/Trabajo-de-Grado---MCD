# Trabajo de Grado - MCD

Este repositorio contiene el proyecto del trabajo de grado para el análisis de datos climáticos NEX-GDDP CMIP6 en Sudamérica.

## Qué incluye

- `scipts/`: scripts para preparar el entorno, extraer y verificar los datos climáticos.
- `raw/`: estructura de directorios para los datos sin incluir los archivos reales.
- `processed/`: resultados procesados del conjunto de datos.
- `outputs/`: salidas y análisis generados.
- `models/`, `logs/`, `tmp/`: carpetas de apoyo usadas por el pipeline.

## Nota importante

El repositorio mantiene la estructura de datos pero no incluye los datos climáticos en bruto. Los `README.md` dentro de `scipts/` y `raw/` explican el flujo y la organización.
