# raw/

Esta carpeta contiene únicamente la estructura de directorios del conjunto de datos NEX-GDDP CMIP6 recortado para Sudamérica.

Estructura esperada:
- `raw/<modelo>/<escenario>/<variable>/`
- Modelos: ACCESS-CM2, CanESM5, CESM2, EC-Earth3, GFDL-ESM4, IPSL-CM6A-LR, MIROC6, MPI-ESM1-2-HR
- Escenarios: `historical`, `ssp126`, `ssp245`, `ssp370`, `ssp585`
- Variables: `tas`, `hurs`
